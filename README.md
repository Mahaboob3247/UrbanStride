# UrbanStride

A modern social fitness platform inspired by Strava and designed for Indian metro cities.

## Features

- GPS Activity Tracking
- Running
- Walking
- Cycling
- Route Discovery
- Fitness Communities
- Events
- Emergency SOS
- Safety Score

## Tech Stack

Frontend:
- React Native
- Expo
- TypeScript

Backend:
- NestJS
- PostgreSQL

Cloud:
- AWS

DevOps:
- Docker
- GitHub Actions
